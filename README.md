## Артефакты лабораторной работы

| Файл | Описание | Команда / Назначение |
| :--- | :--- | :--- |
| `mephi-screenshot.png` | Скриншот терминала с результатами выполнения ключевых команд. | Визуальное подтверждение работы. |
| `stat.out` | Вывод команды `stat` для проверки атрибутов файлов. | Анализ прав доступа и метаданных. |
| `getcap.out` | Вывод команды `getcap` для проверки файловых возможностей (capabilities). | Поиск файлов с расширенными привилегиями. |
| `suid_files.out` | Список файлов с установленным битом SUID. | Выявление потенциально уязвимых исполняемых файлов. |
| `privileged_processes.out` | Список процессов, запущенных от имени привилегированных пользователей. | Анализ активных привилегированных процессов. |
| `sudoers.out` | Копия файла `/etc/sudoers`. | Демонстрация настроек прав sudo. |
| `passwd.out` / `shadow.out` | Выдержки из файлов паролей и хешей. | Анализ учетных записей пользователей. |
| `group.out` | Информация о группах пользователей. | Проверка членства в группах. |
| `my_cat` / `my_chown` | Пользовательские скрипты или результаты работы с правами. | Демонстрация понимания работы прав доступа (по заданию). |
| `testfile.txt` | Тестовый файл для проверки прав доступа. | Практическая проверка операций чтения/записи. |
